# 남양주시장애인복지관 개관 20주년 개인 QR 접수 시스템

현재 운영 구조는 **1인 1신청 · 1인 1QR**입니다.

## 공개 초대장
- https://flydown98.github.io/nyjwel20thVIPCHECK/
- 개인 신청 / 개인 QR / 좌석 확인
- 전체 좌석 자세히 보기
- 마지막 확인 좌석 오프라인 캐시

## 관리자
- https://flydown98.github.io/nyjwel20thVIPCHECK/admin
- 설치형 관리자 PWA
- 참가자 검색/수정/참여불가
- 고속 QR 체크인
- 300석 좌석배치도: A~O 15줄 × 좌10 + 우10
- VIP 24석
- 장애인(휠체어) 42석
- 좌석번호 기반 행운추첨
