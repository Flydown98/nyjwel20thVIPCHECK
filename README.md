# 남양주시장애인복지관 20주년 QR 접수 시스템 — 시제품

GitHub Pages에서 바로 실행할 수 있는 정적 웹 시제품입니다.

## 들어 있는 기능

- 참가자 수기 등록
- CSV 참가자 명단 불러오기·내보내기
- 선착순 접수번호 및 개인 고유코드 자동 생성
- 개인 QR코드 보기·PNG 저장
- 전체 참가자 QR 명찰 일괄 인쇄
- 휴대폰 카메라 QR 스캔
- 이름·연락처·좌석·접수번호 수동 검색
- 도착 처리와 중복 접수 확인
- 좌석 티켓 보기·인쇄
- 관리자 현황판
- 좌석별 도착 여부 확인

## 매우 중요한 제한사항

현재 시제품은 `localStorage`를 사용합니다. 따라서 데이터는 **접속한 브라우저 한 곳에만 저장**됩니다.

- 노트북에서 등록한 참가자 명단은 다른 휴대폰에 자동으로 나타나지 않습니다.
- 여러 접수자가 동시에 사용하면 기록이 합쳐지지 않습니다.
- 브라우저 데이터가 삭제되면 참가자 기록도 사라질 수 있습니다.

실제 행사 운영 전에는 Google Apps Script, Firebase 또는 Supabase 같은 공용 데이터베이스를 연결해야 합니다.

## 가장 빠르게 실행하기

1. 이 폴더의 모든 파일을 GitHub 저장소에 업로드합니다.
2. GitHub 저장소의 `Settings` → `Pages`로 들어갑니다.
3. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
4. Branch를 `main`, 폴더를 `/(root)`로 선택하고 저장합니다.
5. 잠시 뒤 표시되는 GitHub Pages 주소를 엽니다.

## CSV 형식

첫 줄에 아래 열 이름을 사용합니다.

```csv
이름,연락처,좌석번호,구분,비고
홍길동,010-1111-1111,A-01,이용인,
```

필수 열은 `이름` 하나입니다. 나머지는 비어 있어도 됩니다.

## 휴대폰 QR 스캔

GitHub Pages 주소를 휴대폰 크롬 또는 사파리에서 열고 `QR 접수` → `카메라 시작`을 누릅니다. 카메라 권한을 허용해야 합니다.

## 테스트 순서

1. 예시 참가자의 `QR` 버튼을 누릅니다.
2. QR 이미지를 다른 화면 또는 종이에 띄웁니다.
3. 휴대폰에서 같은 사이트를 연 뒤 `QR 접수`에서 스캔합니다.
4. 도착 완료와 좌석번호가 나타나는지 확인합니다.
5. `좌석표`에서 해당 좌석이 초록색으로 바뀌는지 확인합니다.

단, 다른 기기에서는 데이터가 공유되지 않으므로 현재 시제품 테스트는 같은 기기 또는 CSV 내보내기·불러오기를 이용해야 합니다.

## 사용 라이브러리

- QRCode.js 1.0.0 — QR 생성
- html5-qrcode 2.3.8 — 카메라 QR 인식

두 라이브러리는 인터넷을 통해 CDN에서 불러옵니다.
