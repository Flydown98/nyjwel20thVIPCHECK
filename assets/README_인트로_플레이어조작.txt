인트로 영상 플레이어 기능

PC와 모바일 모두 다음 기능을 사용할 수 있습니다.

- 재생 / 일시정지
- 10초 뒤로
- 10초 앞으로
- 진행바를 끌어서 원하는 시간으로 이동
- 현재 재생 시간 / 전체 영상 길이 표시
- 소리 켜기 / 음소거
- 초대장 바로보기

영상 파일:
PC / 가로: assets/intro.mp4
모바일 세로: assets/intro_mobile.mp4

영상이 끝나면 자동으로 초대장으로 넘어갑니다.
처음 자동재생은 브라우저 정책 때문에 음소거 상태로 시작합니다.
'소리 켜기'는 모바일에서도 표시되며 사용자가 직접 누르면 오디오가 활성화됩니다.
